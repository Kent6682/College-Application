# schools — 校系分則與比較表

放具體到「校系」層級的資料。這是真正決定志願的顆粒度。

每份比較表建議欄位：

- 校系名稱與組別
- 招生名額（一般生／各項外加名額）
- 學測**檢定標準**（門檻，未達直接淘汰）
- 學測**採計科目**與加權
- **篩選倍率**（各科目的篩選順序與倍率）
- **指定項目甄試**方式與佔分（面試／筆試／實作／書審）
- 二階甄試日期（用來檢查校系之間是否撞期）
- 歷年**過篩級分**（至少前兩年）

> 資料來源一律是簡章**校系分則**。116 簡章公告前，先用 115 版並標示「115 資料，待核對」。
