資料可信度規則

這些資料會被用來做真實的志願決定，所以：

  • 有時效性的內容（簡章版本、時程、篩選標準）一律在檔案開頭註明學年度與整理日期。
  • 區分已查證與推估。沿用舊學年度資料、或屬於判斷的排序與建議，明確標示，不寫成官方定論。
  • 分則資料表用 🟢 已查證 ／ 🟡 需核對 ／ ⚪ 待查 標示每一格。查不到的不猜、留空。
  • 官方資料以 大學甄選入學委員會、大學入學考試中心、大學招生委員會聯合會 為準；補習班與媒體整理只能當輔助。

已知限制：本專案的整理環境無法直連 cac.edu.tw 與各大學官網（組織網路政策），
資料多為搜尋取得的二手摘要。所有網址與數字請自行連線核對。

網站建置

本 repo 同時是 GitHub Pages 網站，內容由上述 Markdown 自動產生。

pip install markdown
python3 tools/build_site.py      # 新增或修改 .md 之後重跑，產生的 HTML 一起 commit

.nojekyll 讓 Pages 直接提供根目錄靜態檔，不經過 Jekyll。 不要手改產生出來的 .html，會被下次建置覆蓋；要改版型或圖表請改 tools/build_site.py。

歸檔規則

  • 檔名：YYYY-MM-DD-主題.md
  • 新增檔案後，同步更新該目錄的 README.md 索引與本頁索引
  • 在 Markdown 裡寫 <!-- diagram:名稱 --> 可插入產生器內建的流程圖

本站資料為升學備戰整理，非官方文件。日期與規定一律以 大學甄選入學委員會、 大學入學考試中心 公告的簡章為準。
