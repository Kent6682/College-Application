網站

本 repo 同時是一個 GitHub Pages 網站，內容由上述 Markdown 自動產生。

pip install markdown
python3 tools/build_site.py      # 新增或修改 .md 之後重跑，產生的 HTML 一起 commit

產生器是 tools/build_site.py；.nojekyll 讓 Pages 直接提供根目錄的靜態檔，不經過 Jekyll。 不要手改產生出來的 .html，要改版型請改產生器。

歸檔規則

  • 每次對話產出的內容，依主題放進上表對應目錄，不堆在根目錄。
  • 檔名格式：YYYY-MM-DD-主題.md（例：2026-09-15-電機資訊類校系比較.md），方便依時間排序。
  • 每個目錄的 README.md 是該類別的索引，新增檔案時同步補一行說明。
  • 資料若有時效性（簡章版本、時程、篩選標準年度），在檔案開頭註明學年度與整理日期。
  • 區分「已查證」與「推估」：沿用舊學年度或個人判斷的內容要明確標示，不要寫成官方定論。

1. 大學甄選入學委員會（繁星推薦＋申請入學的主管單位）

  • 116 學年度申請入學專區：https://www.cac.edu.tw/apply116/
  • 115 學年度申請入學專區（現在就能看，當範本用）：https://www.cac.edu.tw/apply115/
  • 委員會首頁：https://www.cac.edu.tw/

網站上會有三樣一定要用的東西： 1. 簡章總則 —— 報名資格、報名費、志願數上限（最多 6 個校系）、分發規則等共同規定。 2. 校系分則查詢系統 —— 逐一查每個校系的學測採計科目、檢定標準、篩選倍率、指定項目甄試項目與佔分比例。這是選校選系時真正天天在用的工具。 3. 歷年篩選標準一覽表 —— 查某系去年、前年幾級分過篩，用來評估自己的落點。 例：https://www.cac.edu.tw/cacportal/apply_his_report/110/110_sieve_standard/collegeList.htm（把網址中的年度數字換成想查的學年度）

五、理工科系選擇菜單

下面把理工相關科系分成 8 個家族。請從中挑出 2–3 個家族，我再針對你挑的家族，把 20 校裡對應的校系拉出來做採計科目、篩選倍率、歷年過篩級分的比較表。

依據 ColleGo!（教育部選才育才輔助系統）的 18 學群分類，理工相關主要落在 資訊學群、工程學群、數理化學群、地球環境學群，部分生醫工程橫跨生命科學學群。
