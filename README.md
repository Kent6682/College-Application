# 大學申請入學 備戰專案

> 適用對象：**現高一（115 學年度入學）**，方向 **A 家族 電機資訊類（第二類組）**
> 目標升學年度：**118 學年度**（2029 年 9 月入學），學測在 **民國 118 年 1 月**
> 最後更新：2026/09/21

這個 repo 收集大學申請入學的備戰資料，同時是一個 GitHub Pages 網站。
所有內容依分類存放，逐年更新。

## ⚠️ 年度對照

| 你的年級 | 學年度 | 期間 |
|---|---|---|
| **高一（現在）** | 115 | 2026/9 – 2027/6 |
| 高二 | 116 | 2027/9 – 2028/6 |
| 高三 | 117 | 2028/9 – 2029/6 |
| 大一 | 118 | 2029/9 起 |

- 你考的是 **118 學年度學測**（民國 118 年 1 月，西元 2029 年 1 月）。
- 你要看的是 **118 學年度招生簡章**，預計 **民國 117 年 11 月初**（2028/11）公告。
- 本站多數資料以 **115／116 學年度**整理，那是**範本不是你的年度**——年份加 2 就是你的時間軸。流程結構每年幾乎不變。

## 資料可信度規則

這些資料會被用來做真實的志願決定，所以：

- 有時效性的內容（簡章版本、時程、篩選標準）一律在檔案開頭註明**學年度**與**整理日期**。
- **區分已查證與推估**。沿用舊學年度資料、或屬於判斷的排序與建議，明確標示，不寫成官方定論。
- 分則資料表用 🟢 已查證 ／ 🟡 需核對 ／ ⚪ 待查 標示每一格。**查不到的不猜、留空。**
- 官方資料以 [大學甄選入學委員會](https://www.cac.edu.tw/)、[大學入學考試中心](https://www.ceec.edu.tw/)、[大學招生委員會聯合會](https://www.jbcrc.edu.tw/) 為準；補習班與媒體整理只能當輔助。

> **已知限制**：本專案的整理環境無法直連 cac.edu.tw 與各大學官網（組織網路政策），
> 資料多為搜尋取得的二手摘要。**所有網址與數字請自行連線核對。**

### 網站建置

本 repo 同時是 GitHub Pages 網站，內容由上述 Markdown 自動產生。

```bash
pip install markdown
python3 tools/build_site.py      # 新增或修改 .md 之後重跑，產生的 HTML 一起 commit
```

`.nojekyll` 讓 Pages 直接提供根目錄靜態檔，不經過 Jekyll。
**不要手改產生出來的 `.html`**，會被下次建置覆蓋；要改版型或圖表請改 `tools/build_site.py`。
