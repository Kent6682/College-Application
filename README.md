本 repo 同時是一個 GitHub Pages 網站，內容由上述 Markdown 自動產生。

```bash
pip install markdown
python3 tools/build_site.py      # 新增或修改 .md 之後重跑，產生的 HTML 一起 commit
```

產生器是 `tools/build_site.py`；`.nojekyll` 讓 Pages 直接提供根目錄的靜態檔，不經過 Jekyll。
不要手改產生出來的 `.html`，要改版型請改產生器。

### 歸檔規則

- 每次對話產出的內容，依主題放進上表對應目錄，不堆在根目錄。
- 檔名格式：`YYYY-MM-DD-主題.md`（例：`2026-09-15-電機資訊類校系比較.md`），方便依時間排序。
- 每個目錄的 `README.md` 是該類別的索引，新增檔案時同步補一行說明。
- 資料若有時效性（簡章版本、時程、篩選標準年度），在檔案開頭註明**學年度與整理日期**。
- 區分「已查證」與「推估」：沿用舊學年度或個人判斷的內容要明確標示，不要寫成官方定論。

- 116 學年度申請入學專區：`https://www.cac.edu.tw/apply116/`

```

   ↓

   ↓

   ↓

   ↓

   ↓
```

### 五、理工科系選擇菜單

下面把理工相關科系分成 8 個家族。**請從中挑出 2–3 個家族**，我再針對你挑的家族，把 20 校裡對應的校系拉出來做採計科目、篩選倍率、歷年過篩級分的比較表。

> 依據 ColleGo!（教育部選才育才輔助系統）的 18 學群分類，理工相關主要落在 **資訊學群、工程學群、數理化學群、地球環境學群**，部分生醫工程橫跨生命科學學群。
